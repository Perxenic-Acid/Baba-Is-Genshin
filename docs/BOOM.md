# BOOM (M9.5H)

Primary reference: installed Data/blocks.lua 1388-1469, between SINK removals and
WEAK. Every surviving BOOM source explodes even when another blast selects it.
Radius is active BOOM declaration count minus one, capped to board extent; square
Chebyshev distance includes diagonals. One BOOM affects the same cell. Unsafe
sources destroy themselves; other unsafe victims must share FLOAT. SAFE guards
each identity independently and does not disable a safe source's blast.

The existing frozen contact frame supplies current multiplicities after SINK.
Victims are deleted once with HAS products, followed by WEAK newborn grace and
whole-tree Undo. No recursive newborn explosions run in that phase. EMPTY/scoped
LEVEL explosion and native presentation are deferred. Production tests cover
radius, SAFE, HAS, Undo and FLOAT; full suite retains the 2M startup cap. These
checks are not native acceptance or a complete original-source oracle.

The installed BOOM loop now has a 256-case host-normalized source oracle covering
one to four declarations, diagonal/range boundaries, SAFE/FLOAT, Text and multiple
blast sources. This supplements the production transaction tests.

M9.8L adds late virtual EMPTY BOOM with count-scaled square range, SAFE, real and
virtual HAS stages, target-coordinate EMPTY FLOAT queries, BONUS/terminal prefixes
and whole-tree Undo. The installed BOOM/floating oracle covers 1,280 cases.
Scoped LEVEL BOOM and native mutable victim ordering remain pending; see
[EMPTY_LIFECYCLE.md](EMPTY_LIFECYCLE.md).

Ordinary BOOM now retains physical declaration/source groups in transient
projection data. Installed blocks.lua scans offsets with x outermost, then y,
then findallhere's tile list; it selects the unsafe source last. The backend sorts
eligible real targets by x/y/cell_order (unit_order fallback), preserving that
sequence without enumerating unoccupied square cells. Already selected sources
still explode; repeated victims are deduplicated for once-per-victim HAS. SAFE
independently protects source/targets and FLOAT filters only non-self victims.
Capability-only diagnostic worlds retain their legacy sorted fallback.

The installed ordinary BOOM oracle now compares ordered first-encounter identities
in 1,024 cases, including reversed source/tile order and duplicate declarations,
radius, Text, SAFE/FLOAT and overlapping explosions. A compiled scheduled turn
checks coordinate order, source-last HAS allocation/facing, duplicate grants and
whole-turn Undo. Native dense-list pairs deletion uses our explicit encounter-order
convention. Separate EMPTY/scoped loops and frozen phase timing remain unchanged;
these tests do not establish native presentation or full scheduling parity.
