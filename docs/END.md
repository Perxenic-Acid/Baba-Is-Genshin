## Contact evidence and results

END does not destroy its object. Surviving YOU/YOU2 touch same-FLOAT END, including
self-contact. SELECT cannot trigger it. Conditions, NOT, BROKEN, MIMIC and GROUP
use normal rule-derived capabilities. DONE and ordinary destruction run first;
MAKE products can participate. Capture END immediately before BONUS removal and
late CRASH, so collecting an END/BONUS object still ends. Preview emits no host
sound, particle or credits calls. Surviving CRASH or compiler terminal locks prevent
ending progress/dispatch, retaining the triggering board as usual.

RW_ResolveEndContact returns one deterministic witness record (source/target kind,
identity and optional position), not persisted property state. Ordinary WIN ignores
END/DONE real-unit targets, matching the original separate END and WIN branches.
Scoped LEVEL END tests matching map FLOAT against real YOU, Empty's global
placeholder layer, or scoped YOU itself. Ordered scoped END/WIN/DEFEAT uses the
first eligible terminal property; conversion retains precedence. Scoped YOU may
observe real/Empty END; its WIN query takes precedence over END, as in levelblock().
This also fills the existing scoped YOU + real/Empty WIN contact route.

## EMPTY details

Compiler projection retains transient control/control2/end/float/win declaration
presence. Like original findallfeature, a declared Empty placeholder exists even
when zero cells qualify. Global scoped queries use this presence (including global
FLOAT declaration presence); they must not substitute a particular qualifying cell.
Unconditional NOT cancels its trait's declaration without canceling another alias.
Complex conditional cancellation retains the shared documented placeholder gap.

Local Empty END preserves the original asymmetric endpair/bonuspair check: a leading
END followed by YOU/YOU2 can end, a leading YOU cannot. Projection records ordered
pair state only on virtual cells; no entities or negative proxy IDs are committed.
Empty WIN takes precedence, unsafe DEFEAT suppresses ending. Empty DONE is only an
original sound flag and does not suppress logical ending. DONE.md corrects its prior
assumption about Empty alive suppression. Full synthetic contact lifecycle/BOOM/
MELT/unlock interactions remain part of the broader Empty subsystem gap.

## Tree progress and Undo

After a nonterminal winning turn with END evidence, level action records normal
win plus tree.ending={kind="end",instance_id,source,target} before returning to the
parent. This historical completion fact survives authored runtime reloads and
navigation; it is not a third Undo-only state. Whole-tree Undo restores outcomes,
active level, parent/child runtime and the previous ending fact. Actual end events
are added only on the chosen win route, and native diagnostics dispatch after
successful whole-tree Commit. Conversion/earlier scoped outcomes suppress scoped
END progress when they take priority.
