## Input contract

Backend move/wait actions accept optional player=1 or player=2; absent means 1.
Other channel values reject before input/chance/RNG metadata or compilation.
YOU projects control; YOU2 independently projects control2. The second channel
selects YOU2; if its real-unit/EMPTY list is absent, it falls back to YOU. Sleeping
YOU2 units count for selection before SLEEP prevents motion. Dual-property units
move once per action. The transient displacement projection never changes the
world's original rule-derived contact capabilities.

Original findallfeature inserts an EMPTY sentinel even with no qualifying cells.
A transient empty_control2_declared projection flag preserves its effect on fallback;
unconditional NOT declarations remove it. This flag is not a saved world fact.
LEVEL fallback is independent of the ordinary-unit list. Supported unconditional
LEVEL YOU2 shifts the map through the existing REVERSE/lock/SLEEP/Undo mechanism.

Both channels count for ordinary WIN, DEFEAT (including self-DEFEAT), and scoped
WIN presence. Neither implies SELECT. Defeat-with-SELECT freezes both control
channels (including virtual cells) while retaining selector movement/confirmation.
SELECT follows the existing single action direction on either input channel.
